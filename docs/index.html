DEPT. 00

What this is actually for

This is the last Word MCP server you will need to install. Nothing else in the category comes close on capability: 222 operations reach every part of a Word document that serious work touches, and the survey further down this page is mostly empty columns. Completeness is only half of it. Your documents stay open in Word while the agent edits them, so each change appears in the window in front of you rather than arriving as a file you have to reload, and there is a backup before every change, made without you asking. Nothing you have written gets lost here.

For the academic

A committee returns the manuscript covered in tracked revisions, and the citation apparatus has to survive the rewrite. The scholarly furniture that other tools trample, from footnotes to the reference list, is first-class here, so an agent can take on the revision pass without breaking any of it.

For legal, compliance & HR

Contracts, policies, and case files live in Word, and every edit needs an author attached. Edits here can be written as tracked changes, comparing two versions works the way Word itself does it, and redaction actually removes the text, then verifies that it is gone.

For the Word power user

For anyone whose documents are too important to gamble with. Watch the edit land in your own open Word window, take it back with a single Ctrl+Z if you don't like it, and know there was a backup before anything was touched. You keep the cursor; the agent does the typing.

JUST IN New on the shelf 2026-09-21

The changes you will notice in KitchenSink4Word 2.2.0. 2026-09-21

  • New: Move a paragraph without rebuilding it. Its formatting, hanging indent and bookmarks move with it. It works on a document that is not open in Word. A paragraph that carries a section break will not move, and a move into a different section is refused unless you allow it, because the paragraphs would take on that section's page setup, headers and footers.
  • Fixed: Combined documents keep their source formatting. When you combine documents and keep source formatting, bold, italic, color, underline, borders, shading, tabs, framed paragraphs, paragraph marks, list alignment and inherited styles now survive where the two files disagree. Anything that cannot travel is listed with a plain reason.
  • Fixed: Theme colors and table designs survive a merge. Where two templates give the same theme color a different meaning, carried content keeps the colors Word actually showed; those colors no longer follow the destination's theme. A table style with the same name but a different look is brought in under its own name, and adding the same source again reuses it.
  • Fixed: Style and paragraph-format changes keep what you did not touch. Updating an existing style no longer rebuilds it and strips omitted settings. Formatting a paragraph range now reaches every selected paragraph, including each paragraph mark.
  • Fixed: Citation checks cannot pass with unchecked citations. Citations it cannot match are separated into two lists, single-surname authors and longer author phrases such as organizations or two authors, and the check does not pass until both are empty. An organization that is in your reference list now passes.
  • Fixed: Fields, outlines and contents lists see the whole document. Refresh reaches every header, footer and text area; heading detection is more careful about titles, captions and bold lead-ins; and each table of contents returns its own entries. Page numbers in headers and footers finish updating when Word opens and lays out the file.

The changes you will notice in KitchenSink4Word 2.1.3 and the Version 2 line. 2026-09-16

  • New: Edits stop when the target is unclear. If the same phrase appears in more than one place, the assistant shows the choices instead of editing the first match.
  • Faster: Documents open faster. Version 2.1 cut document opening time roughly in half.
  • Fixed: Word is detected correctly. The server no longer reports that Word is missing when it is installed.
  • Fixed: Safer work with more than one assistant. Two sessions working in the same document now wait their turn instead of combining or overwriting text.
  • Fixed: Backups tell the truth. If a requested backup cannot be made during live editing, the result now says so instead of silently claiming success.
DEPT. 01

Why this exists

An AI agent once needed fifteen minutes to edit twenty table cells in a Word document. Not because the agent was slow, but because every Word MCP server on the market was missing something. One couldn't delete a table column. Another had no footnotes. A third couldn't touch a table of contents. Installing all three still couldn't do the job.

So instead, this got built: one server with everything. The twenty-cell edit now takes one call and finishes in twenty milliseconds. Your agents will simply never know the struggle.

DEPT. 05

Installation

Works with Claude Desktop, Claude Code, Codex, and other AI apps that support local MCP servers, including open-source clients.

ChatGPT on the web uses a separate remote connection. These local installers do not configure it.

Windows. The current Word desktop bundle is Windows-only. File editing works without Microsoft Word; features that control Word require it to be installed.

Choose your computer and the app you use. Open its instructions below.

KitchenSink4Word requires Windows and Microsoft Word. Our Excel, PowerPoint and Web tools also work on Mac and Linux.

Choose your AI app

Claude Desktop

  1. Set up the launcher once

    These tools use uv, a small launcher. If you already installed it for another KitchenSink product, skip to the next step.

    Open the Windows Start menu, type PowerShell, and open Windows PowerShell. Copy this command, paste it into that window, and press Enter.

    Open Terminal on your Mac or Linux computer. This command downloads and runs the official uv installer. Paste it into Terminal and press Enter.

    winget install --id=astral-sh.uv -e

    When it finishes, close and reopen your command window before continuing.

    Launcher help

  2. Download your extension

    Download for Claude Desktop (Community Edition)

    This .mcpb file is for Claude Desktop. Your browser usually saves it in Downloads.

  3. Add it to Claude Desktop

    In Claude Desktop, open Settings → Extensions → Advanced settings → Install Extension. Select the .mcpb file you downloaded, then fully quit and reopen Claude Desktop.

  4. Check that it worked

    Open Settings → Extensions and check that your KitchenSink extension is enabled. Start a new chat and ask the app to use its KitchenSink tools to show the server information. A successful tool result confirms it is connected.

Need a hand?

If uvx is not found, fully quit and reopen your app after setting up uv. If the server still will not connect, or a menu is missing, follow the app guide or contact us with the error message. Do not send private files.

Get setup help

For developers: pip, uvx, source, other MCP clients

Install the package and point any MCP client at the executable:

$ pip install kitchensink4word

Then in any client's config: {"mcpServers": {"word": {"command": "kitchensink4word"}}}. Running from a clone works the same way; point the command at the word-mcp executable in the clone's virtual environment. Full setup, including the sandbox options, is in the README.

Engineered Not to Corrupt

You know the morning: the manuscript is due, Word opens, and there is a dialog offering to "repair" your file. That morning is what this whole server is built to prevent. Before any change, a backup is made automatically. Every save is checked before it replaces your file, so a bad write cannot take the original with it. And everything the edit doesn't touch, from equations to textboxes, passes through exactly as it was, byte for byte. Two full stress campaigns and a shelf of long, heavily formatted real manuscripts, and Word has never once offered to repair anything this server saved.
